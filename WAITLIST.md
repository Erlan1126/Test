# Skyrise waitlist

Ideas approved for a later update. Nothing here is built yet; do them in this order when
the go-ahead comes.

## 1. Show what each run added to Skyhaven
- Results screen: the finished tower, its final height and the residents it added.
- Count the gain into the city total, then offer **Build Again** as the main button.
- Show the latest finished tower in the city (save it first if it isn't saved yet).
- Use the existing city save, and check that restarting or reopening the results can't
  credit the same run twice.

## 2. Give narrow towers a way to recover
- In the clip, the tower climbs from 95 m to 120 m and gains only 8 residents.
- Keep rewards tied to floor size, but add a small width recovery after several precise
  drops in a row on a narrow tower, and show it clearly when it happens.
- Test that it helps a skilled player recover while narrow drops stay challenging.
- Needs a new rules version so older ranked towers still replay.

## 3. Celebrate landmarks in the progress bar
- At 55 m the bar has already switched from Niagara Falls to the Statue of Liberty.
- Briefly celebrate the landmark first, then show the next target with the distance left,
  e.g. "38 m to the Statue of Liberty".
- Keep the timing independent of taps so the player can keep dropping floors.

## 4. Clarify the "Your best" badge
- It changes while the tower sits at 120 m. Find which stat it really shows.
- Label it with the measure and unit, e.g. "Best height 140 m" or "Best streak 13", using
  the existing records.

## 5. Simplify the home screen
- Keep **Start Building** as the main button.
- Put Daily, Journey and Zen behind one **Modes** button.
- One clear place to collect rewards.
- Check that all three modes, collecting rewards, and City, Shop and Goals still work on a
  phone-sized screen.

## 6. Soften shrinking floors
- Shrink by at most about 25% (now 45%).
- A perfect drop gives back the full width.
- A clear "shrinking" label and a ticking sound.
- Needs a new rules version so older ranked towers still replay.

## Final check (after 1–5)
Play one complete run into the city, start another, and check the population totals, the
landmark change, the record label and the new home screen.
