Six screenshots, in this order, for both stores. Every image shows the real game
(a daytime town named "Maple Bay"), with a caption at the top.

## Where each set goes

- `app-store-6.9/` (1290 × 2796): App Store Connect → your app → the version page →
  "iPhone 6.9" Display". Drag all six in, in order.
- `app-store-6.3/` (1206 × 2622): the same page, "iPhone 6.3" Display", if it asks for it.
- `google-play/` (1080 × 1920): Play Console → Grow → Store presence → Main store listing →
  Phone screenshots.

The Skyrise screenshots in `../app-store-screenshots/` and `../google-play-screenshots/` are
for the tower game and stay as they are.
