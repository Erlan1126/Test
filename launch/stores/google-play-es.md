# Skyrise: Google Play Console (español)

The Spanish store listing. In the Play Console go to Grow → Store presence → Main store
listing → **Manage translations** → **Add your own translations**, pick
**Spanish (Latin America) – es-419** (and, if you like, **Spanish (United States) – es-US**
and **Spanish (Spain) – es-ES** with the same text), then paste each field below.

The game itself switches to Spanish automatically on phones set to any Spanish language.
